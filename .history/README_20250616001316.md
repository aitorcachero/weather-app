# 🌤️ Weather App - Aplicación del Clima con React

Una aplicación moderna del clima desarrollada con React y Tailwind CSS que proporciona información meteorológica en tiempo real para cualquier ciudad del mundo.

![React](https://img.shields.io/badge/React-18.2.0-blue?logo=react)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.3.6-38B2AC?logo=tailwind-css)
![Vite](https://img.shields.io/badge/Vite-4.4.5-646CFF?logo=vite)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Características

- 🌍 **Búsqueda global**: Consulta el clima de cualquier ciudad del mundo
- 📱 **Diseño responsive**: Optimizado para desktop y dispositivos móviles
- 🎨 **Interfaz moderna**: Diseño glassmorphism con efectos visuales atractivos
- 💾 **Historial de búsquedas**: Almacenamiento local de las últimas consultas
- 🌈 **Fondos dinámicos**: Cambio automático de fondo según las condiciones climáticas
- ⚡ **Carga rápida**: Optimizado con Vite para un rendimiento superior
- 🔔 **Notificaciones**: Alertas informativas con React Toastify

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React 18.2.0 con hooks personalizados
- **Estilos**: Tailwind CSS 3.3.6
- **Build Tool**: Vite 4.4.5
- **API**: OpenWeatherMap API
- **Notificaciones**: React Toastify
- **Almacenamiento**: LocalStorage para persistencia de datos

## 📋 Información Mostrada

- 🌡️ Temperatura actual y sensación térmica
- 🌤️ Descripción detallada del clima
- 💧 Humedad relativa
- 💨 Velocidad y dirección del viento
- 🌡️ Presión atmosférica
- 👁️ Visibilidad
- 🌅 Hora de amanecer y atardecer
- ☁️ Porcentaje de nubosidad
- 📊 Temperaturas mínima y máxima
